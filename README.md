Генератор розового шума в временной области, реализованный на C++ с использованием Qt и оптимизированной цифровой фильтрации.

Проект предназначен для генерации, визуализации и анализа розового шума с приближением спектра к закону 1/f. Он поддерживает построение графиков исходного сигнала, импульсной характеристики и спектральной плотности мощности (PSD), а также включает настройку параметров коррекции смещения и оптимизации фильтра.

## Что это такое

Розовый шум — это случайный сигнал, в котором мощность на частоте уменьшается пропорционально 1/f. Такой тип шума часто используется в аудио, тестировании систем, моделировании физических процессов и анализе фильтров.

Этот проект генерирует такой шум из белого гауссовского входа через каскад фильтров, а затем визуализирует результат в реальном времени.

## Основные возможности

- Генерация розового шума в временной области
- Аппроксимация спектра по закону 1/f с помощью IIR-фильтров
- Дополнительная корректировка КИХ-фильтра для улучшения формы на низких частотах
- Компенсация паразитного DC-offset
- Отображение:
  - waveform (временной сигнал)
  - impulse response (ИХ фильтра)
  - power spectral density (PSD)
- Оптимизация параметров фильтра по целевой форме
- Генерация гауссовского белого шума и визуализация распределения
- Поддержка FFT и анализа спектра
- Визуальный интерфейс на Qt/QML-подобной графической библиотеке

## Как это работает

Процесс генерации состоит из нескольких этапов:

1. На вход подаётся белый гауссовский шум.
2. Этот сигнал проходит через набор IIR-фильтров, которые приближают спектральную плотность 1/f.
3. Дополнительно применяется небольшая FIR-коррекция, чтобы улучшить точность на низких частотах.
4. Включается коррекция смещения уровня (DC offset), чтобы избежать долгосрочного дрейфа нуля.
5. Полученный сигнал визуализируется на графиках, а при необходимости выполняется FFT-анализ PSD.

Фильтр настраивается параметрами, такими как:

- длина цепочки экспонент
- коэффициенты затухания
- степени аппроксимации закона 1/f
- параметры коррекции DC-offset

## Сборка

### Требования

- CMake 3.16+
- C++20
- Qt 5 или Qt 6
- Компилятор с поддержкой SSE4.1 / SSE4.2

### Windows / Linux

```bash
git clone https://github.com/nawww83/pink_noise_generator.git
cd pink_noise_generator
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

После сборки исполняемый файл будет доступен в каталоге `build`.

Запустите собранное приложение и используйте интерфейс для:

## Примечания по реализации

Проект использует:

- `noisegenerator` для цифровой фильтрации и генерации розового шума;
- `rfft` для быстрого преобразования Фурье;
- `plotter` для визуализации графиков;
- `prng` для генерации случайных значений и гауссовского шума.

Фильтр настроен так, чтобы обеспечивать плавную «розовую» амплитудную характеристику при минимальном дрейфе уровня сигнала.
